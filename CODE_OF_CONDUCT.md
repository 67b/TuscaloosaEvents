# Code of Conduct

## Our Commitment

TuscaloosaEvents is intended to be a welcoming, educational, collaborative, and respectful learning environment.

This project exists not only to build useful software, but also to help people learn:

- Git and GitHub
- Open-source collaboration
- AI-assisted development
- CI/CD workflows
- Automation
- Web technologies
- Problem-solving and teamwork

Contributors of all experience levels are welcome.

We are committed to creating an environment where people feel safe asking questions, making mistakes, learning publicly, and contributing constructively.

---

# Expected Behavior

Participants in this project are expected to:

- Be respectful and constructive
- Assume good intentions
- Welcome beginners and learners
- Offer feedback in a respectful manner
- Be patient with mistakes and questions
- Focus discussions on improving the project
- Respect differing perspectives and experiences
- Help create a positive learning environment

Healthy technical disagreement is acceptable and encouraged when done respectfully.

---

# Unacceptable Behavior

The following behaviors are not acceptable:

- Harassment or personal attacks
- Hate speech or discriminatory language
- Trolling or intentionally disruptive behavior
- Intimidation or bullying
- Public shaming
- Doxxing or sharing private information
- Sexualized language or unwanted advances
- Repeated hostile or unconstructive criticism
- Deliberately misleading contributors
- Submitting malicious code or harmful content

This applies across:
- Issues
- Pull Requests
- Discussions
- Commit comments
- Any project communication spaces

---

# Beginner-Friendly Environment

This project intentionally welcomes:
- new developers,
- students,
- hobbyists,
- and first-time GitHub contributors.

Questions are encouraged.

Mistakes are expected.

Constructive learning is valued more than perfection.

Please help maintain a culture where people feel comfortable learning publicly.

---

# AI-Assisted Contributions

AI-assisted development is allowed and encouraged within this project.

However:
- Contributors remain responsible for what they submit
- AI-generated code should be reviewed carefully
- Transparency and honesty are expected
- Contributors should strive to understand the code they contribute

AI tools should support learning and collaboration, not undermine it.

---

# Maintaining a Healthy Community

Project maintainers may:
- request clarification,
- suggest changes,
- moderate discussions,
- close unproductive conversations,
- or reject contributions that conflict with the goals of the project.

These actions are intended to protect the health and long-term sustainability of the community and repository.

---

# Reporting Concerns

If you experience or witness behavior that violates this Code of Conduct:

- Open a private discussion with the maintainer if possible
- Or open an Issue if appropriate and safe to do so

Please include:
- what happened,
- relevant context,
- and any supporting information.

All reasonable efforts will be made to review concerns fairly and respectfully.

---

# Enforcement

Project maintainers reserve the right to:
- remove comments,
- reject contributions,
- lock discussions,
- or block contributors

…when behavior significantly harms the project environment or community.

Enforcement decisions will aim to prioritize:
- safety,
- fairness,
- collaboration,
- and the educational mission of the repository.

---

# Scope

This Code of Conduct applies to:
- repository discussions,
- Issues,
- Pull Requests,
- commit comments,
- documentation,
- and related community interactions.

---

# Final Thoughts

This repository is ultimately about:
- learning,
- building,
- experimenting,
- collaborating,
- and improving together.

Thank you for helping make this a respectful and constructive environment for everyone.
